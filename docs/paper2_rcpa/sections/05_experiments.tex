\section{Experimental Setup}
\label{sec:experiments}

\subsection{Dataset and receivers}
We use the OSU LoRa 24-device corpus with the \texttt{Diff\_Receivers\_Setup\_Indoor\_SameTx} subset~\cite{elmaghbub2021lora_wild,hamdaoui2022deeplearning}.
Two indoor receivers (RX1, RX2) observe the same transmitter population under controlled indoor conditions.
Each device contributes one capture file per receiver; therefore cross-receiver evaluation is file-level authentication-style testing with window-level support.

\subsection{Checkpoints and transfer directions}
We evaluate cross-receiver transfer in both directions: RX1$\rightarrow$RX2 and RX2$\rightarrow$RX1.
Feature extractors are source-receiver training checkpoints from the hybrid backbone, trained on the source receiver with three random seeds.
Embeddings are extracted once per direction/seed and reused across split repeats.

\subsection{Evaluation protocol}
Each target file is split into 256 deterministic windows grouped into four block-disjoint sets as described in Section~\ref{sec:rcpa}.
Three split repeats rotate block roles.
Main RCPA experiments aggregate $3$ seeds $\times$ $3$ split repeats per direction ($n=9$ runs per direction per method/$K$).
Primary metrics are file-level accuracy and macro-F1; we report mean$\,\pm\,$std unless noted.

\subsection{Methods evaluated}
\textbf{Main:} source classifier, RCPA-S, RCPA-T ($K\in\{1,3,5,10,20\}$), RCPA-B ablation at selected $K$.

\textbf{Supplementary:} entropy-min TTA and pseudo-proto TTA (controlled diagnostic run plus appendix threshold sweep), OOB representation equalization (CORAL on OOB embeddings), and alpha-sensitivity for RCPA-B.

\subsection{Implementation details}
RCPA uses cosine-distance prototype classification with file-level mean embedding voting over query blocks C+D.
No query windows participate in calibration or prototype estimation.
TTA baselines adapt on unlabeled Block~A only.
OOB-Eq applies CORAL between source and target OOB embeddings on calibration windows only; fused embeddings are then used for RCPA-T evaluation in the auxiliary analysis.

\subsection{Fairness and scope boundaries}
We do not compare against multi-receiver retrained receiver-agnostic systems under different enrollment assumptions.
Our goal is to quantify what a frozen same-receiver backbone can recover with honest target-side calibration under strict leakage control.
Cross-day RCPA is out of scope because it mixes a different shift type with the source-only cross-day story of prior backbone work~\cite{paper1_placeholder}.
