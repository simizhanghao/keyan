\section{Conclusion}
\label{sec:conclusion}

We studied cross-receiver LoRa RFFI failure through an OOB-aware diagnosis pipeline and proposed RCPA, a lightweight post-hoc target-receiver prototype calibration method built on a frozen hybrid backbone.
Our analysis shows that OOB features can become receiver-entangled under cross-receiver shift, that source classifier and source prototype decisions are not transferable, and that RCPA-T restores device separability using only $K$ labeled calibration windows per device.
Unsupervised target adaptation remains insufficient under severe collapse, while OOB representation equalization suppresses receiver probe without replacing labeled calibration.
Future work may explore waveform-level OOB equalization and broader deployment scenarios.
