# IoTJ English Manuscript Scaffold

This directory contains the **English IoTJ paper skeleton** for branch `paper-ready-v3`.
The old Chinese draft under `docs/paper_draft/` is a source-notes archive only.

## Structure

```text
main.tex                 # IEEEtran journal entry point
refs.bib                 # Verified references (READ / ABSTRACT_CHECKED only)
reference_candidates.csv # Full candidate database incl. TO_READ / EXCLUDE
sections/                # One file per section
tables/                  # LaTeX tables (numbers from final_tables/)
figures/                 # Generated PDF/PNG figures
```

## Compile (requires TeX Live)

```bash
cd docs/iotj_paper
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Regenerate figures

```bash
python3 scripts/paper/generate_final_figures.py
```

Outputs:
- `outputs/paper_ready_v3/final_figures/`
- `docs/iotj_paper/figures/`

## Numbers policy

All result numbers must come from:
- `outputs/paper_ready_v3/PAPER_RESULTS_SUMMARY.md`
- `outputs/paper_ready_v3/final_tables/*.csv`

Do **not** copy values from the old Chinese tex.

## References policy

1. Add candidates to `reference_candidates.csv` first.
2. Only `READ` or `ABSTRACT_CHECKED` entries go into `refs.bib`.
3. Snowball from downloaded papers, but do not bulk-import unread refs.
