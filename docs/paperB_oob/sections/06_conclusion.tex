\section{Conclusion}
\label{sec:conclusion}
We presented an auditable study of OOB dependence in cross-receiver LoRa RFFI. OOB spectral evidence contains real transmitter-discriminative information, but two distinct OOB-aware backbones learn receiver-sensitive and frequency-structured dependencies. Frozen interventions and strong CIS/receiver-adversarial controls separate this mechanism from the broader claim that cross-receiver RFFI is impossible. Most importantly, a protocol-frozen confirmatory blind evaluation on six previously unopened receivers reproduced both the disruption and left-greater-than-right asymmetry on all six receivers; both backbones satisfied all prespecified criteria. The resulting design lesson is narrow but actionable: OOB evidence should be audited as a potentially useful yet receiver-sensitive feature source, and controlled nuisance robustness should not be used as a substitute for real receiver-held-out validation.
