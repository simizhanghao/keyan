# 第 1 章 绪论

## 1.1 研究背景

低功耗广域网络（Low-Power Wide-Area Network, LPWAN）是物联网（Internet of Things, IoT）大规模连接的重要基础设施。其中，LoRa（Long Range）基于 chirp spread spectrum（CSS）物理层，在 Sub-GHz 频段以较低发射功率实现公里级通信，已被广泛应用于智能抄表、环境监测、资产追踪等场景。随着终端设备数量增长，**设备身份认证**成为网络安全与业务可信的前提：只有经过授权的 LoRa 节点才应被网关接纳并处理其上行数据。

传统认证依赖预置密钥、数字证书或与安全模块（如 SE/TPM）配合的密码协议。对于成本敏感、算力与存储受限的 LoRa 终端，纯密码方案在密钥分发、更新与侧信道防护方面面临持续压力。因此，业界与学术界探索**物理层安全**补充手段，其中射频指纹识别（Radio-Frequency Fingerprint Identification, RFFI）通过区分发射机硬件非理想性来实现「设备即身份」，无需在每次通信中交换长密钥，具有部署灵活、与上层协议解耦等特点。

LoRa RFFI 的研究近年来受到关注，但在真实部署中仍面临多重挑战：采集条件随日期与环境变化而发生漂移；换用不同接收机时观测分布显著偏移；复杂电磁干扰与未知设备入网使闭集识别假设不再成立。本文围绕上述挑战，从建模、跨域校准与复杂环境评估三个层面展开研究，目标是在可复现协议下**提高认证鲁棒性**、**诊断失效机理**并**提供开放集评估框架**，而非声称已完全解决 LoRa 设备认证问题。

## 1.2 传统密码认证与物理层认证的互补关系

密码认证在逻辑层保证消息来源与完整性，其安全性建立在密钥保密与协议正确性之上。LoRaWAN 等标准已定义 Join 与重密钥流程，但终端侧实现质量参差不齐，且大规模密钥管理成本高昂。物理层指纹认证可作为**辅助因子**：在网关侧对上行信号进行射频特征分析，与逻辑层凭证交叉验证，用于检测克隆设备、伪造发射机或未登记硬件。

需要明确的是，RFFI 不能替代密码学认证对语义安全与抗重放的保证；本文关注的是**在既定数据集与协议下提升识别与拒识的可靠性**，为后续与 LoRaWAN 安全模块融合提供算法与评估基础。

## 1.3 射频指纹认证的基本思路

射频指纹源于发射链路中的模拟与混合信号非理想性，包括功率放大器非线性、I/Q 不平衡、载波频偏（CFO）、相位噪声、滤波器频率响应差异等。这些特征在设备生产过程中部分固化，难以通过软件完全抹除，因而可用于区分不同发射机。

RFFI 系统通常包含：信号预处理、特征提取或深度嵌入、分类器或距离度量、以及（在认证场景下）阈值判决。闭集识别假设测试设备均属于训练见过的类别；开放集认证则要求对**未知设备**具备拒识能力。本文贯穿两种设定，并在第 5 章重点讨论开放集指标与 embedding-based scorer 的适用性。

## 1.4 LoRa RFFI 面临的三类挑战

### 1.4.1 跨日期与环境变化

同一接收机在不同日期采集的数据，可能因温度漂移、本振老化、天线位置微调及环境多径变化而导致特征分布偏移。同接收机跨日（same-receiver cross-day）是评估时间鲁棒性的标准设定。本文第 3 章针对该问题提出带外频谱引导的 RF-HSTU 混合模型。

### 1.4.2 跨接收机部署失配

新网关入网或接收机更换时，接收端射频前端引入额外的频率响应与噪声特性，使「设备指纹 + 接收机指纹」的联合分布改变。严格 source-only 跨接收机测试下，闭集准确率可降至接近随机水平。第 4 章诊断接收机诱导的 OOB 特征纠缠，并提出 RCPA-T 进行少样本目标接收机校准。

### 1.4.3 复杂电磁扰动与未知设备

现场存在 AWGN、CFO、窄带干扰、相位噪声、I/Q 失衡、滤波器漂移及复合应力等扰动，闭集精度显著退化。同时，认证系统需拒绝未登记设备。第 5 章构建电磁扰动 benchmark，扩展开放集协议，并分析 CFO 等关键失效模式。扰动一致性训练（EM-CR）仅作初步探索，不作为主方法。

## 1.5 本文研究内容

本文以 OSU LoRa 公开数据集及配套实验协议为基础，围绕「带外证据 + 时序建模 + 跨域校准 + 复杂环境评估」展开：

1. 提出 OOB-guided cross-attentive RF-HSTU，融合带内 IQ 与带外谱证据，提升 same-receiver cross-day 闭集识别性能；
2. 系统诊断 cross-receiver 失败机理，揭示 OOB 路径上的 receiver-induced feature entanglement，并提出 RCPA-T 在 block-disjoint 少样本协议下进行目标接收机原型校准；
3. 建立 LoRa RFFI 复杂电磁扰动评估协议，开展闭集鲁棒性、CNN-IQ 对比、开放集认证及 EM 应力下 open-set 实验，论证 embedding-space scoring 的优势并刻画 CFO 失效边界。

## 1.6 主要创新点

**创新点一（第 3 章）：** 提出 OOB-guided cross-attentive RF-HSTU 混合架构，利用 in-band IQ 与 out-of-band spectral evidence 共同建模 LoRa 硬件指纹，在 same-receiver cross-day 设置下文件级准确率达 75.0±5.3%，较 CNN-IQ 提升约 20.8 个百分点。

**创新点二（第 4 章）：** 诊断跨接收机迁移失败，发现 OOB 路径存在接收机诱导的特征纠缠；提出 RCPA-T，利用每设备 K 个带标签目标接收机窗口构造目标原型，在 block-disjoint 协议下 K=20 时达 75.0%，显著优于 source-only 近随机水平。

**创新点三（第 5 章）：** 构建复杂电磁扰动 benchmark 与开放集未知设备认证协议；系统量化六类扰动及混合应力下的退化规律；证明 Prototype / Mahalanobis 等嵌入空间评分优于 MSP / Energy；指出 CFO 同时破坏已知类分类与未知拒识，为当前系统最强 failure mode。

## 1.7 论文结构安排

- **第 2 章** 介绍 LoRa CSS 原理、射频指纹来源、闭集与开放集认证指标及 OSU 数据集与各类 split 协议；
- **第 3 章** 阐述 OOB-guided RF-HSTU 模型、训练评估协议、主结果与消融，并讨论 cross-receiver stress 局限；
- **第 4 章** 分析跨接收机失配与 OOB 纠缠，介绍 RCPA-T 及同协议 baseline，讨论方法假设与局限；
- **第 5 章** 定义电磁扰动模型，报告闭集鲁棒性、CNN 对比、开放集及 EM 下 open-set 结果，并诚实讨论 EM-CR 初步实验；
- **第 6 章** 总结全文工作、创新点与不足，展望未来研究方向。

## 本章小结

本章从 IoT 与 LoRa 部署背景出发，说明了射频指纹认证对传统密码手段的补充价值，归纳了跨日漂移、跨接收机失配与复杂电磁及开放集三类挑战，概述了本文三条研究主线与创新点，并给出了章节安排。全文强调在可复现协议下提高鲁棒性与可评估性，而非宣称已彻底解决 LoRa 设备认证问题。
